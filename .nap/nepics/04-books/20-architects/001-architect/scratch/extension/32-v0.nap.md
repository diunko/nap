# v0 — isomorphic-git + IDB filesystem

* core idea
  * isomorphic-git + lightning-fs in the browser
  * clone .nap/ into IDB on PR open
  * IDB is a real git repo — full working tree, full git ops
  * Monaco reads/writes to IDB filesystem
  * edits = dirty working tree state (natural git concept)
  * v1 commit = `git.add` + `git.commit` + `git.push` — no GitHub API gymnastics

* data flow
  * detect PR page → extract owner/repo/branch
  * `git.clone({ url, ref: branch, dir: '/' })` into lightning-fs (IDB-backed)
    * shallow clone depth 1 — just latest commit
    * full repo, not sparse — napkins are small
  * file tree reads from IDB fs
  * Monaco creates models from IDB fs reads
  * edits write to IDB fs (auto-save, debounced)
  * "sync" = `git.fetch` + `git.checkout` (or merge)

* side panel layout
  * left: Monaco editor (napkin-markdown)
  * right: file tree (from IDB fs, nap extended mode style)

  * resize handle between them
  * file tree collapsible (panel is narrow ~400px)

* Monaco

  * .md → load in editor
