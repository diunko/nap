# v0 — refined scope (post-POC)

* what the POC proved
  * wterm + just-bash + lightning-fs + isomorphic-git work together
  * bash terminal in browser with git commands against IDB — confirmed
  * ~400 lines of glue: fs-adapter, git command, shell fork
  * Playwright can drive wterm DOM (16 tests, all green)
  * CORS proxy needed for git clone (use public for now)
  * heredoc support added, cwd tracking fixed

* v0 scope: Chrome side panel with three surfaces
  * terminal (bash + git, from POC)
  * editor (Monaco, napkin-markdown)
  * file tree (from IDB filesystem)

* side panel layout
  * top: tab bar (switch between terminal and editor views)
  * main area: active surface
  * right sidebar: file tree (collapsible, ~120px)
    * reads from lightning-fs (same IDB as terminal)
    * click file → opens in editor
    * shows .nap/ structure: architects, napkins, agents as groupings
  * note: Chrome side panel is ~400px wide — tight, every pixel counts

* terminal surface
  * the POC, packaged as a Chrome extension side panel
  * wterm + just-bash + lightning-fs + isomorphic-git
  * git clone, ls, cat, cd, git log/status/diff/add/commit
  * user clones a repo → files appear in the file tree

* editor surface
  * Monaco with napkin-markdown tokenizer (copy from v3)
  * light theme default, detect GitHub dark/light
  * editable — // comments inline
  * shift-enter continuation
  * link styling (underline file:line paths, markdown links)
  * Cmd+click for link navigation
    * file:line → open GitHub file in main tab
    * .md → load in editor
    * https:// → new tab
  * auto-save to IDB fs (debounced, same file the terminal sees)

* shared filesystem
  * one LightningFS instance, two consumers
  * terminal writes (echo, git checkout) → editor sees changes
  * editor writes (auto-save) → terminal sees changes (cat, git status)
  * no watcher needed — both read from same IDB on demand

* git flow
  * clone repo from terminal: `git clone https://github.com/org/repo`
  * browse in file tree, open files in editor
  * add // comments in editor
  * switch to terminal: `git add .`, `git commit -m "review"`, `git push`
  * no commit button UI — terminal IS the git UI

* auth
  * PAT stored in chrome.storage.sync
  * settings popup: paste token, test connection
  * used by isomorphic-git onAuth for clone/push
  * public repos work without token

* what triggers side panel
  * extension icon click → opens side panel
  * auto-detect GitHub PR page → pre-fill clone URL? (nice-to-have)

* testing
  * Playwright + Chrome with `--load-extension`
  * extend POC's test patterns to extension context
  * fixture: real small public repo
  * stories from POC carry forward + new stories for editor + file tree

* what's NOT in v0
  * rendered mode (Cmd+J)
  * localStorage persistence (IDB via git is the persistence)
  * commit button UI (use terminal)
  * workflowy zoom
  * heading decorations
  * nap.app integration
