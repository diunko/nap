# v0 — what ships

* side panel with two areas
  * left: Monaco editor (napkin-markdown, editable)
  * right: file tree (nap extended mode style)
  * clicking file in tree → loads in editor
  * resize handle between them

* data flow
  * detect PR page → extract owner/repo/branch/path
  * fetch folder tree from GitHub API → store in IDB
  * file tree built from IDB
  * editor loads files from IDB
  * IDB is the cache, GitHub is source of truth
  * "sync" button re-fetches and diffs

* Monaco setup
  * napkin-markdown tokenizer (copied from v3)
  * light theme default (match GitHub)
  * detect GitHub dark mode → switch theme
  * word wrap, no minimap, no line numbers
  * editable — // comments inline
  * shift-enter continuation with prefix behavior
    * tab/shift-tab indent subtree
    * `//` is a prefix for shift-enter
    * `* //` is a comment

* link styling
  * tokenizer rules for link patterns (underline + link color)
    * bare `file.ts:42`
    * markdown `[text](url)`
  * separate from click behavior (link provider)

* link navigation
  * file:line → navigate main tab to PR diff file + line
  * .md → load chapter in editor
  * .ts/.tsx → open GitHub blob in new/reused tab
  * https:// → new tab
  * Cmd+click in editable mode

* edits
  * ephemeral — in memory only, gone on reload
  * no persistence, no commit, no auth

* theme
  * light default
  * detect GitHub dark/light from page
  * one light + one dark theme definition

* what's NOT in v0
  * rendered mode (Cmd+J)
  * localStorage persistence
  * GitHub API commit
  * auth / PAT
  * workflowy zoom
  * heading size decorations
