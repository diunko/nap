### For future agents: how to test in this monorepo

**Always run from the repo root.** All scripts are wired through the root package.json.

#### Commands

| what | command |
|------|---------|
| v2 typecheck | `npm run typecheck:v2` |
| v3 typecheck | `npm run typecheck:v3` |
| v2 small tests (vitest) | `npm run test:v2:small` |
| v3 small tests (vitest) | `npm run test:v3:small` |
| v2 medium tests (playwright) | `npm run test:v2:medium` |
| v3 medium tests (playwright) | `npm run test:v3:medium` |
| v2 build | `npm run build:v2` |
| v3 build | `npm run build:v3` |
| v2 CLI build | `npm run build:cli -w packages/v2` |
| v3 CLI build | `npm run build:cli -w packages/v3` |
| single playwright test | `cd packages/v2 && NAP_TEST=1 npx playwright test -g "T-XXXX-YY"` |

#### Pitfalls

1. **`electron-rebuild` runs at root, not per-package.** Native modules (`node-pty`, `better-sqlite3`) are hoisted to root `node_modules/`. The per-package dirs have no `node_modules/`. If medium tests fail with "Timeout waiting for window" — native modules are built for Node, not Electron. Fix: `npx electron-rebuild` from root. This runs automatically on `npm install` via root `postinstall`.

2. **CLI electron resolution walks up.** `nap open` finds `node_modules/.bin/electron` by walking up from the package root (or `NAP_APP_PATH`). It does NOT assume electron is in the package's own `node_modules/`. This is because npm workspaces hoist everything.

3. **Medium tests need a build first.** The `test:medium` script does `npm run build && npm run build:cli && NAP_TEST=1 npx playwright test`. If you run playwright directly, make sure you've built first. Stale builds = mysterious failures.

4. **Run failing tests one by one.** The medium suite has 232 tests with 50% parallelism. When debugging, use `-g "T-XXXX-YY"` to isolate. Some tests share Electron instances via `beforeAll` — a failure in one cascades to all siblings.

5. **T-1100-11 is flaky.** Skipped. Watcher race condition during rapid nepic switching (~25% failure rate). Pre-existing, not caused by the monorepo move.

6. **Playwright runs from package dir, not root.** `npx playwright test -w packages/v2` does NOT work. Either `cd packages/v2` first, or use the root wrapper `npm run test:v2:medium`.
